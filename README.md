# خريطة الحقول النفطية والغازية العراقية

موقع ويب تفاعلي (Static Website) باللغة العربية يعرض حقول النفط والغاز في العراق على خريطة تفاعلية، مع بيانات جيولوجية وتشغيلية لكل حقل، فلاتر، بحث، لوحة إحصائية، صفحة تفاصيل مستقلة لكل حقل، ومساعد دردشة محلي.

## هيكل المشروع

```
├── index.html        الصفحة الرئيسية (الخريطة + الفلاتر + الإحصاءات + الدردشة)
├── field.html         قالب صفحة تفاصيل الحقل (field.html?id=rumaila)
├── style.css           التصميم الكامل (RTL، أزرق داكن / ذهبي / أبيض)
├── script.js           منطق الصفحة الرئيسية (الخريطة، الفلاتر، البحث، المساعد)
├── field.js            منطق صفحة تفاصيل الحقل
├── data.json            قاعدة بيانات الحقول (19 حقلاً)
├── icons/                أيقونات SVG (علامات الخريطة، الشعار، صورة بديلة)
└── images/              مجلد لصور الحقول الحقيقية (فارغ حالياً — انظر أدناه)
```

## طريقة التشغيل

الموقع Static بالكامل ولا يحتاج خادماً أو بناءً (build). يكفي فتح `index.html` في المتصفح، لكن يُفضَّل تشغيله عبر خادم محلي بسيط حتى يعمل `fetch('data.json')` بشكل صحيح في كل المتصفحات (بعض المتصفحات تمنع قراءة الملفات المحلية عبر `file://`):

```bash
# باستخدام بايثون (مثبت افتراضياً على أغلب الأنظمة)
cd iraq-oil-fields-map
python3 -m http.server 8080
# ثم افتح المتصفح على http://localhost:8080
```

أو ببساطة اسحب مجلد المشروع إلى إضافة "Live Server" في VS Code.

## النشر على GitHub Pages أو Netlify

- **GitHub Pages:** ادفع محتويات هذا المجلد إلى مستودع GitHub، ثم فعّل GitHub Pages من إعدادات المستودع (Settings → Pages) واختر الفرع الرئيسي (main) والمجلد الجذر (root). لا حاجة لأي إعداد بناء إضافي.
- **Netlify:** اسحب المجلد مباشرة إلى واجهة Netlify Drop (netlify.com/drop)، أو اربط المستودع من GitHub واترك أوامر البناء فارغة (Build command: none, Publish directory: `/`).

## قاعدة البيانات (data.json)

كل سجل حقل يحتوي على الحقول التالية:

| الحقل | الوصف |
|---|---|
| `id` | معرّف فريد يُستخدم في رابط صفحة التفاصيل |
| `name` | اسم الحقل |
| `governorate` | المحافظة |
| `lat` / `lng` | الإحداثيات |
| `company` | الشركة المشغّلة |
| `type` | نفط / غاز |
| `status` | منتج / قيد التطوير / إنتاج محدود |
| `formations` | مصفوفة التكوينات المنتجة |
| `source_rocks` | مصفوفة الصخور المصدرية |
| `reservoir` | نوع الصخر الخزني |
| `cap_rock` | الصخر الغطاء |
| `age` | العمر الجيولوجي |
| `depth` | العمق التقريبي |
| `api` | درجة API إن وجدت |
| `description` | وصف موجز |
| `references` | قائمة مراجع نصية عامة |
| `images` | مصفوفة مسارات صور (فارغة حالياً) |

لإضافة حقل جديد: أضف كائناً جديداً بنفس البنية إلى `data.json`. الموقع يقرأ الملف بالكامل عند التحميل، فلا حاجة لتعديل أي كود آخر.

### إضافة صور حقيقية

لم تُدرَج أي صور فعلية في هذا المشروع احتراماً لحقوق الملكية الفكرية للصور غير المرخّصة. لإضافة صور حقيقية موثّقة المصدر لأي حقل:

1. ضع ملفات الصور داخل مجلد `images/` (مثلاً `images/rumaila-1.jpg`).
2. أضف مسارات هذه الملفات إلى مصفوفة `images` الخاصة بالحقل في `data.json`.
3. ستظهر الصور تلقائياً في صفحة تفاصيل الحقل.

## حدود المحافظات على الخريطة

تُحمَّل حدود محافظات العراق تلقائياً من مصدر مفتوح خارجي (geoBoundaries عبر jsDelivr CDN) عند توفر اتصال بالإنترنت. إن تعذّر الاتصال (مثلاً أثناء التطوير دون إنترنت) تستمر الخريطة بالعمل بشكل طبيعي بدون طبقة الحدود، وتبقى مواقع الحقول وأسماء المحافظات على خريطة الأساس (Tile Layer) ظاهرة.

## مساعد الدردشة (متّصل بذكاء اصطناعي حقيقي عبر Google Gemini)

المساعد يحاول أولاً الاتصال بدالة خلفية آمنة (`netlify/functions/chat.js`) تستخدم **Google Gemini API** للإجابة على أي سؤال (سواء عن حقول قاعدة البيانات أو أسئلة جيولوجية عامة). إذا لم تُفعَّل الدالة بعد (مثلاً أثناء التطوير المحلي بدون Netlify)، يعود المساعد تلقائياً إلى محرك قواعد محلي بسيط يجيب من `data.json` مباشرة — بحيث لا يتعطّل الموقع أبداً.

### خطوات تفعيل الاتصال الحقيقي بالذكاء الاصطناعي (5 دقائق)

**1) احصل على مفتاح API مجاني من Google:**
- افتح **https://aistudio.google.com/app/apikey**
- سجّل الدخول بحساب Google واضغط "Create API Key"
- انسخ المفتاح (يبدأ عادة بـ `AIza...`)

**2) انشر الموقع عبر Netlify مع ربط Git (وليس السحب المباشر Drop):**
الدوال الخلفية (Functions) تحتاج نشراً عبر ربط مستودع Git، لأن خاصية "السحب والإفلات" (Netlify Drop) لا تدعم الدوال الخلفية:
- ارفع محتويات هذا المجلد إلى مستودع GitHub
- من لوحة Netlify: **Add new site → Import an existing project** واختر المستودع
- اترك إعدادات البناء كما هي (لا حاجة لأمر بناء، `publish = "."` محدّد مسبقاً في `netlify.toml`)

**3) أضف المفتاح كمتغيّر بيئة (وليس داخل الكود):**
- من إعدادات الموقع على Netlify: **Site configuration → Environment variables → Add a variable**
- الاسم: `GEMINI_API_KEY`
- القيمة: المفتاح الذي نسخته من Google AI Studio
- احفظ، ثم أعد نشر الموقع (Trigger deploy) حتى تُطبَّق المتغيّرات الجديدة

بعد هذه الخطوات، المساعد بالموقع سيجيب فعلياً بذكاء اصطناعي حقيقي متصل بالإنترنت على أي سؤال، مع معرفة كاملة ببيانات جميع الحقول (لأن الدالة الخلفية تُحمّل `data.json` تلقائياً كسياق مرجعي لكل سؤال).

### ملاحظات أمان مهمة
- **لا تضع مفتاح API داخل `script.js` أو أي ملف بالواجهة الأمامية مطلقاً** — أي زائر يكدر يشوفه ويستخدمه على حسابك.
- المفتاح موجود فقط داخل بيئة Netlify (Environment Variables) ويُستخدَم حصراً من داخل الدالة الخلفية `netlify/functions/chat.js` التي تعمل على خوادم Netlify، لا على متصفح الزائر.
- يمكن استبدال Google Gemini بأي نموذج آخر (مثل Claude عبر Anthropic API) بتعديل بسيط داخل `netlify/functions/chat.js` فقط.

## التقنيات المستخدمة

- HTML5 / CSS3 / JavaScript (بدون أي إطار عمل)
- [Leaflet.js](https://leafletjs.com) لعرض الخريطة التفاعلية
- بلاطات خرائط داكنة من CARTO (`dark_all`) لتناسب الهوية البصرية
- خطوط Google Fonts: Cairo (العناوين) وTajawal (النصوص) وRoboto Mono (الأرقام والإحداثيات)
- `data.json` كقاعدة بيانات ثابتة (يمكن استبدالها لاحقاً بملف Excel محوَّل إلى JSON، أو بخادم API حقيقي)

## ملاحظة حول دقة البيانات

بعض القيم الجيولوجية والتشغيلية (خصوصاً الإحداثيات الدقيقة لبعض الحقول الأقل توثيقاً، ونطاقات العمق، ودرجة API) تقديرية استناداً إلى الأدبيات العامة، وتحتاج تدقيقاً رسمياً من وزارة النفط العراقية أو الشركات المشغّلة والمسح الجيولوجي العراقي (GEOSURV) قبل استخدامها في أي تقرير فني أو تعاقدي.
