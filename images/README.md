# مجلد صور الحقول

ضع هنا صور الحقول النفطية والغازية الحقيقية (بصيغة jpg أو png أو webp)، ثم اربط مسار كل صورة داخل مصفوفة `images` الخاصة بالحقل المعني في ملف `../data.json`.

مثال:

```json
"images": ["images/rumaila-1.jpg", "images/rumaila-2.jpg"]
```

لم تُدرَج أي صور افتراضية في هذا المشروع احتراماً لحقوق الملكية الفكرية للصور غير المرخّصة.
